# English Syntax

An offline Android app for learning English syntax by building sentence trees yourself.

It has 29 short lessons, from the basics (what is a phrase?) to ideas from modern linguistics. Each lesson has a brief explanation, a worked tree diagram, and a hands-on exercise where you select words, choose labels (NP, VP, PP, S, CP, AdjP, AdvP), and build the tree. The app gives instant feedback on what is correct, missing, or mislabeled, and explains why.

Topics include constituents, phrases and clauses, PP attachment and ambiguity, complements vs. adjuncts, constituency tests, phrase structure rules, X-bar theory, theta roles, Case, binding, movement, passives, control and raising, island constraints, principles and parameters, and the Minimalist Program.

Progress is saved on your device, and the lessons work fully offline.
